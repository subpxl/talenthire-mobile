Device E2E lives in **`../integration_test/`** (Flutter tooling requirement).

Run from repo root:

```powershell
cd ..
flutter test integration_test/core/launch_and_auth_test.dart -d <deviceId>
```

See `../integration_test/README.md` for run commands and **`../integration_test/STUB_COMPLETION_GUIDE.md`** to finish stub tests.
